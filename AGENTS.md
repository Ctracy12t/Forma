# Forma source and release workflow

Use `Ctracy12t/Forma` as the source of truth for Forma code, design, fonts and font license notices, frontend, backend, and cybersecurity configuration and documentation. Commit and verify changes in GitHub before deploying the corresponding website changes to the existing Vercel project, `forma-listing-films` in `forma-ba97`. Verify the deployment against the committed source. Follow Connor's directions when he marks work GitHub-only. Keep that work off the live website, using a separate branch for deployable changes or a path outside the deployed output for reference files.

The repository is public. Keep credentials, private customer data, and sensitive security details in approved private storage. Document required environment variable names without values. Commit font files and design assets only when their license permits public redistribution.

See `DEPLOYMENT.md` for the current deployment and local preview instructions.
